Each key is an env var in every box you own. Its value in the box is a placeholder; the box's network adds the real key in its place only on requests to the hosts you list. Programs in your box can use the key on those hosts while the box runs, but cannot read it. A write share hands its guests the same use. CocoonBox never shows a key again after you save it.
